# FenrirOS Changelog

## Version 0.4.0 Alpha — In Development

### Added
- Initial Calamares graphical installer integration.
- Support packages for BIOS and UEFI installation.
- Disk partitioning and filesystem management utilities.
- Initial support for encrypted installations using LUKS.

### Testing
- Install FenrirOS onto a virtual hard drive.
- Verify booting independently of the live ISO.
- Validate user account creation and bootloader installation.
- Test UEFI compatibility and encrypted installations.
